WHAT THE SETUP SCRIPT DOES:
---------------------------

  1. ✓ Checks for Python 3.10+, Podman/Docker, Git
  2. ✓ Configures Podman for rootless operation
  3. ✓ Creates Python virtual environment (with uv if available)
  4. ✓ Builds Python wheel package
  5. ✓ Stages files for Docker build
  6. ✓ Builds Docker image (ytdl-sub:local)
  7. ✓ Tests the built image

COMMON ISSUES & FIXES:
---------------------

  Issue: "permission denied" (Podman)
  Fix:
    echo "$(whoami):100000:65536" | sudo tee -a /etc/subuid
    echo "$(whoami):100000:65536" | sudo tee -a /etc/subgid
    podman system migrate

  Issue: "pip3: command not found"
  Fix:
    source .venv/bin/activate
    # (setup script handles this automatically)

  Issue: "Cannot connect to Docker daemon"
  Fix:
    ./setup-build-environment.sh --use-docker
    # OR: sudo usermod -aG docker $(whoami)
